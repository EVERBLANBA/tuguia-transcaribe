# 📱 Configuración para Segundo Plano en Móviles

## 🚀 Tu Guía ahora soporta ejecución en segundo plano!

### ✨ Nuevas funcionalidades implementadas:

- 🔄 **Service Worker** para funcionamiento offline
- 📍 **Tracking GPS continuo** en segundo plano
- 🔋 **Modo ahorro de batería** automático
- 🌐 **Optimización según conexión** de red
- 🔔 **Notificaciones** de proximidad al destino
- 📱 **Optimizaciones específicas** para móviles

## 📋 Instrucciones de configuración:

### 1. 🔔 Habilitar notificaciones
```
1. Abre la aplicación en tu navegador móvil
2. Cuando aparezca "¿Permitir notificaciones?" → Presiona "Permitir"
3. Las notificaciones te alertarán cuando llegues al destino
```

### 2. 📍 Configurar ubicación
```
1. Cuando aparezca "¿Permitir ubicación?" → Presiona "Permitir"
2. Asegúrate de seleccionar "Permitir siempre" o "Mientras usas la app"
```

### 3. 📱 Configurar para segundo plano

#### En Android:
```
1. Ve a Configuración → Aplicaciones
2. Busca tu navegador (Chrome, Firefox, etc.)
3. Presiona "Batería" → "Optimización de batería"
4. Busca tu navegador y marca "No optimizar"
5. En "Permisos" → "Ubicación" → "Permitir todo el tiempo"
```

#### En iOS (Safari):
```
1. Ve a Configuración → Safari
2. Activa "Ubicación" en Configuración → Privacidad y seguridad
3. En Configuración → Tiempo de pantalla → "Límites de app"
4. Agrega Safari a las excepciones
```

### 4. 🎯 Usar la navegación inteligente

1. **Planifica tu ruta** en la página principal
2. Presiona **"¡Yo te llevo!"**
3. En la nueva página, presiona **"Iniciar Guía Inteligente"**
4. **¡Listo!** Ahora puedes:
   - Minimizar la app
   - Usar otras aplicaciones
   - Bloquear la pantalla
   - **La navegación seguirá funcionando en segundo plano**

## 🔔 Qué notificaciones recibirás:

- 📍 **"Faltan 300 metros"** - Prepárate para llegar
- 🎯 **"¡Has llegado!"** - Ya estás en tu destino
- 🔋 **"Modo ahorro activado"** - Batería baja detectada
- ⚠️ **"Error de GPS"** - Problemas con la ubicación

## 🔋 Modo ahorro de batería automático:

Cuando tu batería esté por debajo del 20%:
- ⚡ Reduce la frecuencia del GPS
- 🎨 Desactiva animaciones innecesarias
- 📡 Optimiza el uso de datos
- 💓 Reduce la frecuencia de actualizaciones

## 📊 Optimizaciones automáticas:

### Por tipo de conexión:
- **WiFi/4G/5G**: Máxima calidad y frecuencia
- **3G**: Calidad media, menos actualizaciones
- **2G**: Modo optimizado, solo lo esencial

### Por tipo de dispositivo:
- **Gama alta**: Todas las funciones habilitadas
- **Gama media**: Animaciones reducidas
- **Gama baja**: Modo optimizado completo

## 🛠️ Solución de problemas:

### ❌ "No funciona en segundo plano"
```
1. Verifica que diste todos los permisos
2. Desactiva la optimización de batería para tu navegador
3. Reinicia la aplicación
4. Asegúrate de presionar "Iniciar Guía Inteligente"
```

### ❌ "No recibo notificaciones"
```
1. Ve a configuración del navegador
2. Verifica que las notificaciones estén habilitadas
3. Verifica que no esté en modo "No molestar"
```

### ❌ "El GPS no es preciso"
```
1. Sal a un área abierta (sin edificios altos)
2. Espera 1-2 minutos para que se estabilice
3. En modo ahorro de batería la precisión es menor (normal)
```

### ❌ "Consume mucha batería"
```
1. El modo ahorro se activará automáticamente al 20%
2. Puedes cerrar otras aplicaciones no necesarias
3. Conecta el cargador si es posible durante viajes largos
```
